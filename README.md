# Advanced Geometric Satellite Geodesy

**Teaching Assistant | K. N. Toosi University of Technology**

Welcome to the course assignment repository.

This repository provides assignment descriptions, computational resources, and submission instructions for Geometric Satellite Geodesy.

## Assignments

### Exercise 01 — GNSS Orbit Computation
- Kepler equation
- Satellite position and velocity
- ECI and ECEF frames
- Orbital visualization

### Exercise 02 — Broadcast vs Precise Orbits
- Broadcast ephemeris
- IGS precise orbit (SP3)
- Interpolation
- RAC error analysis

## Submission

Each student must submit their assignments through their individual private GitHub repository.
